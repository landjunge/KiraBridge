## Admission and execution are different events

Explicit `background=true` routes `terminal.execute` to the managed executor.
Native admission still owns the fresh one-shot request. Its old30s observer knew
terminal input evidence but ignored the executor's persisted `local_process_spawned`
record, so it cancelled execution even when the allowed runtime was45s.

The fix accepts `process_started` only for the current runtime's exact admitted
background route, immutable arguments, own RUNNING lease and identical persisted
typed spawn evidence. It releases the admission wait, retaining actual execution
and its reservation until the process ends. It creates no paste, Return,
acknowledgement or completion claim. Pre-start timeout, cancellation, busy
reservation and historical queue isolation remain enforced.
