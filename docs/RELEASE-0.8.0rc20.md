# KiraBridge 0.8.0rc20 · Intel macOS

Closing a terminal and opening a new one can reuse the same macOS TTY name.
Old uncertain handoffs no longer block that successor after fresh native observations
prove the original window and both original processes are gone. A TTY name alone
does not establish a session identity. Live or unproven original sessions remain
protected; old work is never automatically replayed.

Repeated automatic binding replacements retain their original configuration anchor,
so a service restart restores the latest verified successor. Explicit manual binding
changes remain authoritative.

The Swift companion and Python runtime identify this candidate by version and source
commit. Installation and native acceptance evidence is recorded in
[the repair report](ISSUE51-SHELL-PROMPT-20261030.md). This Intel candidate does not
certify other platforms, hosted CI, notarization, or all ChatGPT Live/Voice workflows.
