# KiraBridge 0.6.0rc2 · Private Release Candidate

## Deutsch

KiraBridge für Vibe Coding: ChatGPT übergibt besprochene Entwicklungsaufträge an
Codex oder Grok auf dem eigenen Rechner; Zusammenarbeit am selben Projekt ist mit
eingerichteten Rechten möglich. Weitere CLI-Anbindungen sind geplant.

Neu: geführter Start aus einem geprüften Paket, KiraBridge-ASCII-Banner,
DE/EN-Schritte, automatische Voraussetzungserkennung, Benutzerlaufzeit und
wiederverwendeter ChatGPT-Einrichtungshelfer. Bestehende gesunde Konfigurationen
und Schlüssel werden erhalten; verwaltete Updates prüfen wartende/aktive Queues.
Vorherige Reparaturen: getrennte Lesepfade, nachvollziehbare Vorabprüfung,
strukturierte Fehler in vorhandener Auditkette, beobachtbare MCP-Verbindungsphasen
und keine automatischen Wiederholungen unklarer Schreibaufträge.

Dies ist **keine stabile1.0** und keine öffentliche Veröffentlichung. Pakete für
macOS15 Intel/Apple Silicon und Ubuntu24.04 x86_64 werden gezielt geprüft; ein Linux-Desktop-/
systemd-Benutzersitzungsnachweis und die Bedienabnahme auf einem frischen fremden
Rechner sind gesonderte Kriterien. Ein bestehender bestätigter ChatGPT-Dateiaufruf
belegt die aktuelle eigene Installation, nicht jedes neue Konto oder den RC-Assistenten.
Kontofunktionen können fehlen; Tunnelbereitschaft ist keine Zielchat-Abnahme.

Dieser neue RC2 enthält die vom Betreiber auf main gespeicherte Netzwerkpunkt
Personal Use License1.0, mit maßgeblicher deutscher Fassung und englischer
Übersetzung. LICENSE liegt im Bundle, Python-Paket und separat bei. Paketmetadaten:
`LicenseRef-Netzwerkpunkt-Personal-Use-1.0`. Private nicht geschäftliche Nutzung
ist kostenlos; geschäftliche Nutzung, Weiterverkauf und kostenpflichtige Dienste
benötigen gesonderte schriftliche Erlaubnis. Keine allgemeine Weiterverteilung.
Fremdlizenzen und historische Rechte bleiben erhalten. Individuelle Vorlage,
kein OSI-Standard und nicht anwaltlich geprüft. RC1-Pakete bleiben unverändert;
sie werden nicht nachträglich als neu lizenziert bezeichnet.

KiraBridge bleibt privat. Öffentliches Paket, Discussion und Subdomain benötigen
weiterhin die gesonderte Veröffentlichungsfreigabe. Drittanbieterabhängigkeiten
und der begrenzte ältere Intel-Kryptografiepin bleiben vor Veröffentlichung zu prüfen.

## English

Built for Vibe Coding: ChatGPT passes discussed development tasks to Codex or Grok
on your computer. Both may collaborate on the same project with configured
permissions. More CLI integrations are planned.

New: one guided start from a verified package, KiraBridge ASCII banner, DE/EN
steps, prerequisite detection, user runtime and the reused ChatGPT setup helper.
Existing healthy settings/keys are preserved. Managed updates require drained
queues. Earlier repairs provide scoped read paths, concrete preflight, structured
diagnostics in the existing audit chain, observable MCP lifecycle phases and no
automatic replay of uncertain writes.

**Not stable1.0 or a public release.** Targeted checks cover macOS15 Intel/Apple Silicon and
Ubuntu24.04 x86_64 packages. Real Linux desktop/user-systemd acceptance and usability
on a fresh external machine remain separate criteria. Existing user-confirmed
ChatGPT file access proves the current private installation, not every account
or the new RC wizard. Tunnel readiness does not prove a target chat call.

RC2 includes the operator-adopted Netzwerkpunkt Personal Use License1.0:
German governs, English is a translation. LICENSE is bundled, included in Python
package metadata and supplied separately. License expression:
`LicenseRef-Netzwerkpunkt-Personal-Use-1.0`. Free private non-business use;
business use, resale and paid services need separate written permission.
No general redistribution permission. Third-party licenses and historical rights
remain. Custom terms, not an OSI standard and not legally reviewed. Earlier RC1
artifacts are unchanged and are not relabeled as newly licensed.

KiraBridge remains private. Public package release, Discussion and the planned
subdomain still need separate publication approval. Review third-party dependencies
and the older Intel-only cryptography pin before publication.
