# KiraBridge 0.8.0 RC40

This candidate combines the Big Plan integration with all fifteen additional
main commits, including the Windows setup wizard and pinned offline tunnel client.
It includes native coordinator continuation, bound timing receipts, passive CLI
returns, remote restart recovery, CLI modules and the RC39 input fixes.

The Linux CI duration fix gives the existing self-hosted lanes twenty minutes
and flushes bounded preflight provenance. Hosted Mac workflows remain manual.

Source integration, CI, package acceptance, installation and continued operation
are recorded separately in the dated integration evidence. Historical UNKNOWN
receipts are preserved; this release does not replay them or enable AutoNext.

This is a macOS Intel candidate. Windows main commits are preserved; their native
acceptance remains the separate recorded Windows scope. ARM is not accepted here.
