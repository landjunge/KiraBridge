# KiraBridge 0.8.0rc22 · macOS system and communication modules

Modular native system/application/window/AX/capture/notification/
preference/process capabilities, fixed public macOS reports, complete owned output
ranges and stable directory pagination. The native App is included and pinned
inside each macOS runtime package; no post-install Swift compiler is required.

Visible agent handoffs still contain only the original message body. A proven
local Codex final answer can satisfy the default reply request without adding a
prompt wrapper or inventing a mailbox acknowledgement. Wrapped logical newlines
and soft wraps are checked using the actual widget layout.

See [the architecture, contracts and verification status](SYSTEM-COMMUNICATION-20261031.md).
OS permission requests are separate explicit operations. Denied rights and
unsupported targets remain explicit refusals. This release does not certify
Apple Silicon, untested OS versions, notarization or every third-party app.

Package, acceptance and running identities are recorded separately with exact
source commits and hashes; the version label alone is not runtime proof.
