## Installation (für den Organisator)

Im eigenen sichtbaren Terminalfenster ausführen. Vorher prüfen, dass 0 Tasks aktiv sind.

```sh
S="$HOME/.local/state/rc45-mac-20261109"
B="$S/package-check/extracted/KiraBridge"
shasum -a 256 "$S/artifacts/KiraBridge-macos.tar.gz"
# erwartet 3f1ef3af28c0f3c52bb63ccf6f5b70cda911ed780ce0d057b1ae4fb3a18fd18d
# 1. ThreadDesk-Quelle bereitstellen und in der Config wählen
cp -Rp "$S/threaddesk-aa940db" "$HOME/.local/share/kirabridge/install/shared/threaddesk-aa940db"
sed -i '' 's#shared/threaddesk-770bbc9/src#shared/threaddesk-aa940db/src#' "$HOME/.config/kirabridge/config.toml"
# 2. RC45 installieren
/usr/local/opt/python@3.11/bin/python3.11 "$B/installer/install.py" install \
  --bundle "$B" --desktop --require-visible-terminal
```

Readbacks danach:

- `current.json`, CLI `status` und MCP `bridge_health` melden 0.8.0rc45 und `releases/0.8.0rc45-0b1d937eef06`.
- Die Abschlussprüfung meldet ThreadDesk mit der Quelle `threaddesk-aa940db`.
- In Kira liefert `td_get_thread` `truncated` und `next_offset`. `td_list_threads` zeigt keine Papierkorb-Threads mehr.
- `td_search_threads` braucht die Freigabe durch den Besitzer: einmal `threaddesk search --enable` im Board-Workspace.

**Rückweg:** Die Config-Zeile wieder auf `threaddesk-770bbc9/src` setzen. Danach im sichtbaren Fenster mit demselben Paket ausführen:

```sh
/usr/local/opt/python@3.11/bin/python3.11 "$B/installer/install.py" rollback \
  --bundle "$B" --require-visible-terminal
```
